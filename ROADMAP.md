# Roadmap

What's planned for TabCabin. Finished items move to the [changelog](CHANGELOG.md).

## Release

- [ ] Publish the extension in the Chrome Web Store (see
      [`docs/chrome-web-store`](docs/chrome-web-store/README.md))

## Polish

- [ ] Ask for the name and icon right away when creating a new workspace
- [ ] Remove the sync icon from the top right corner
- [ ] Settings: keep the title bar visible (sticky) while scrolling
- [ ] Settings in Polish: "Konto i synchronizacja" is too long and wraps badly — shorten it
- [ ] Creating an account: ask for the password twice so a typo doesn't lock you out
- [ ] Settings: clicking TabCabin next to the version opens the website

## New

- [ ] Onboarding for first-time users
- [ ] Templates — ready-made workspaces with groups (for example "Work": Projects, Meetings, Read
      later; "Home": Shopping, Recipes, Trips); offered in onboarding and when creating a new
      workspace
- [ ] Inbox — save a page in one click without picking a group, sort it later
- [ ] Save and close a whole window as one group, restore it in one click
- [ ] Warn when a link is already saved in another group (with a setting to turn it off)
- [ ] Mark broken links (pages that no longer load) with a small icon
- [ ] Actions in search (`⌘K`): move the tab to a group, open a group, add a note
- [ ] Calm stats — for example "84 tabs closed this week", no streaks or badges
- [ ] Share a group with a read-only link
- [ ] Boards on the web: sign in on the website and use it on a phone, maybe as an installable app
      (PWA)

## Website

- [ ] Comparison pages: TabCabin vs Toby, OneTab, tabExtend

## Later

- [ ] Tags, with a filter in search
